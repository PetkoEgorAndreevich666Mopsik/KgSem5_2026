# Ландшафт: квадродерево, LOD и Frustum Culling

Ландшафт 512 × 512 метров загружается из пользовательской карты Height.png. Исходная 16-битная карта 1024 × 1024 приведена к сетке 1025 × 1025 и разбита на 16 тайлов с общими краями. Высоты приведены к диапазону 0–60 м. Albedo_Out.png задаёт цвет, Normals_Out.png — нормали в мировых осях с Y вверх. Исходники скопированы в assets/terrain; при запуске они не перезаписываются генератором шума.

## Запуск в CLion

Открой эту папку как проект CMake, выбери профиль Debug с компилятором Visual Studio и запусти CG_Sem2. Рабочая папка: `$ProjectFileDir$/cmake-build-debug`. Для загрузки планеты и Sponza используется прежний загрузчик Assimp; путь ASSIMP_DIR указан в CMakeLists.txt.

## Управление

- NumPad 1 — ландшафт (он же открывается по умолчанию).
- NumPad 2 — планета.
- NumPad 3 — Sponza.
- WASD — полёт, Q/E — вниз/вверх, Shift — ускорение.
- ПКМ + мышь — поворот камеры.
- 3 — материал ландшафта.
- 4 — нормали.
- 5 — сетка и цвет уровня LOD.
- 8 — включить/выключить Frustum Culling.
- 9 — включить/выключить LOD. При выключении выбираются самые подробные листья дерева.

NumPad используется при включённом NumLock. Обычные цифры 3/4/5 и 8/9 сохраняют прежние привязки; с NumPad они не пересекаются.

В режиме ландшафта заголовок окна показывает FPS, число нарисованных участков, число отброшенных узлов и распределение выбранных участков по уровням 0–4. Нулевой уровень — весь ландшафт, четвёртый — самые подробные участки.

## Устройство

Terrain строит квадродерево из 341 узла. У каждого узла сетка 32 × 32 ячейки. LOD выбирается только по расстоянию: порог деления равен удвоенной ширине участка. Для возврата к крупному участку нужно отдалиться ещё на 20%, чтобы сетка не переключалась около одного порога. Вертикальное расстояние считается относительно общей средней высоты всего ландшафта; форма отдельных холмов и стенки не влияют на выбор. Разница LOD соседей ограничена одним уровнем. После выбора детализации участки вне пирамиды видимости отбрасываются по квадродереву. Родитель и потомки одновременно не рисуются.

Нормали вычисляются по полной карте высот, поэтому освещение на стыках согласовано. По краям каждого участка идут вертикальные стенки (skirts) до общего основания на 10 м ниже минимальной высоты. Они закрывают щели разных LOD и опускают внешнюю границу ландшафта вниз. У внешних стенок отдельные вершины, нормали и более тёмный цвет. Внутренние стенки сохраняют освещение поверхности. Стенки не отбрасывают искусственные тени на землю. Смена LOD дискретная, без плавного морфинга. В теневые каскады отправляются подробные листья без наложения родительских сеток.

## Проверки

В CLion можно запустить CTest TerrainChecks или цель TerrainTests с аргументом `../assets/terrain` и рабочей папкой cmake-build-debug. Проверяются загрузка и совпадение границ тайлов, индексы, нормали, границы геометрии, изменение детализации с расстоянием, полное покрытие без наложений и отсечение ландшафта вне обзора.

## Импорт карт

Запусти tools/import_terrain.py с аргументом — папкой с Height.png, Albedo_Out.png и Normals_Out.png. Требуются Python, NumPy и Pillow только для подготовки файлов. Готовому приложению они не нужны. Скрипт сохраняет исходные PNG, создаёт R16/PGM-тайлы и проверяет совпадение краёв. Нормали используют исходную ориентацию Y вверх; выборка текстур ограничена краями, чтобы не появлялся шов от повторения изображения.
